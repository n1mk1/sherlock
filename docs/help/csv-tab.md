# The CSV tab

## Edit cells
Double-click a cell to edit it, add or delete rows, then Save. Saving makes a new version and the dashboard updates the widgets that read the changed columns.

## Find and sort
Use Find to search the rows and the column headers to sort. A link like "Open these rows in CSV" from chat or a model card shows only those rows; clear the filter to see all of them again.

## The Changes panel
Every cleaning step and every saved edit is listed with what it changed, its code, and Undo.
