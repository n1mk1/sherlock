# The dashboard

## Widgets
Each widget is a query over the current version of your data. How do you know? under a widget shows the exact SQL it runs. The menu (the three dots) changes the view, duplicates, collapses or deletes it; a deleted widget can be brought back from the toast.

## Filter by clicking
Click a bar or a slice to filter every other widget to that category. Click it again, or the × on the filter chip, to clear it.

## Add a widget
Add widget opens a drawer: describe the chart in words, or start from a template. In chat, ask "add a chart of fare by port to the dashboard".

## Arrange the dashboard
Edit layout lets you drag and resize widgets. The layout is saved for this file.

## Story cards
The story panel on the right has one card per widget, written from numbers computed in code. Every number is a chip: hover it to see where it came from. A card marked changed was rewritten after the data changed; outdated means it waits for Refresh.
