# Getting started

## Load a file
Drop a CSV anywhere on the page, or use Upload CSV in the library on the left (.csv, .tsv or .txt, up to 50 MB). A preview shows how the file reads, with the delimiter, encoding, header row and rows to skip; change any of them, then press Import. Sherlock reads the file, works out each column's type and role, and lists what looks wrong with it. Try with sample opens the Titanic passenger list, already cleaned, with its dashboard, story cards and an analysis ready.

## Clean it with AI or yourself
After the upload, Sherlock shows what it found and offers two choices. Clean with AI opens the cleaning plan: every fix Sherlock would try, grouped by kind, all ticked. Untick any you don't want, then press Start cleaning; the cleaner fixes one issue at a time and checks each fix before keeping it. Clean it myself builds the dashboard straight away and opens the CSV tab, where you can edit cells by hand or ask the chat. Tick Remember my choice, or set After upload in Settings to Open the cleaning plan or I'll clean it myself, to skip the question; the screen that opens says why, with a Change link. Your original file is never changed: every change is a step that makes a new version, and any step can be undone.

## The three tabs
The Dashboard tab holds the charts Sherlock picked and their story cards. The CSV tab shows the rows, lets you edit cells and lists every change. The Flow tab is a canvas for arranging cards into a story.
