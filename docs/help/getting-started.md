# Getting started

## Load a file
Drop a CSV anywhere on the page, or use Upload CSV in the library on the left. Try with sample loads the Titanic passenger list. Sherlock reads the file, works out each column's type and role, and lists what looks wrong with it.

## Clean it or use it as is
After the upload, Sherlock offers to clean the file. Clean it for me runs the cleaner, which fixes one issue at a time and checks each fix before keeping it. Use as is builds the dashboard straight away. Your original file is never changed: every change is a step that makes a new version, and any step can be undone.

## The three tabs
The Dashboard tab holds the charts Sherlock picked and their story cards. The CSV tab shows the rows, lets you edit cells and lists every change. The Flow tab is a canvas for arranging cards into a story.
